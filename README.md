# MSFS 2024 Cockpit — Elgato Stream Deck Plugin

Native **SimConnect** telemetry and cockpit controls for **Microsoft Flight Simulator 2024**, featuring real-time dynamic SVG keys and a pre-configured 5x3 Stream Deck profile.

## Features

- **Zero External Dependencies:** Connects directly to MSFS 2024 via SimConnect.
- **Pre-Built 5x3 Profile:** Automatically installs a ready-to-fly 15-key layout.
- **Auto-Reconnect:** Displays a clean standby state when MSFS 2024 is closed and reconnects automatically when a flight loads.
- **Live Controls & Telemetry:**
  - Autopilot
  - Flaps (Increment / Decrement + live position)
  - Landing Gear & Parking Brake
  - Lights & Electrical
  - Altitude & Elevator Trim
  - COM1 Radio
  - Caution & Warning Indicators
  - Camera View Toggle (Cockpit / External / Drone)

## Requirements

- Windows 10 or 11 (64-bit)
- Microsoft Flight Simulator 2024
- Elgato Stream Deck App (v6.5+)

## Installation

1. Download the plugin from the **Elgato Marketplace** (or double-click the `.streamDeckPlugin` file).
2. Confirm the installation in the Elgato Stream Deck app.
3. The **MSFS 2024 Cockpit** 5x3 profile will be imported automatically.
4. Launch **Microsoft Flight Simulator 2024** and start a flight — the keys will connect automatically.

## Troubleshooting

- **Keys stay in Standby / Offline:** Make sure MSFS 2024 is running and you are loaded into a flight (not on the main menu).
- **Profile didn't switch automatically:** Open the Stream Deck app → **Settings** → **Profiles** and select **MSFS2024-Cockpit**.
